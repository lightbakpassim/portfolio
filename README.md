#  Cyber-Portfolio | BAKPASSIM Pouwedeo Light

Bienvenue sur le dépôt de mon portfolio professionnel. Il s'agit d'un site web d'une seule page (*Single Page Application*) conçu avec une esthétique moderne, épurée et orientée "cyber-tech" (mode sombre avec des accents néon cyan et green). 

Le site est entièrement responsive, optimisé pour le SEO et met en avant mes compétences en développement Full Stack ainsi que mes intégrations d'Intelligence Artificielle.

##  Aperçu du Site
- **Design :** Dark mode immersif, effets de lueur au survol (glow), animations fluides au défilement (*Fade-in via Intersection Observer*).
- **Sections :** Accueil (Hero), À propos, Compétences (Stack technique), Réalisations (Projets), Tarifs des prestations, et un Formulaire de Contact complet.
- **Hébergement :** Déployé de manière permanente et automatisée sur **Netlify** via intégration continue avec GitHub.

---

##  Stack Technique & Outils

### Frontend & UI
- **HTML5 / CSS3** (Variables CSS avancées pour le thème, animations et structures Flexbox/Grid)
- **Google Fonts** (Polices *Syne*, *Instrument Sans* et *JetBrains Mono*)
- **JavaScript (ES6+)** (Gestion dynamique des animations au scroll et suivi du curseur)

### Mes Compétences Globales (Mises en avant)
- **Frameworks Web :** Vue.js, Nuxt.js, Spring Boot
- **Langages :** JavaScript, Python, Java
- **Intelligence Artificielle :** LLM locaux, Ollama, Watchdog (Python)
- **DevOps & Versioning :** Git, GitHub, Netlify
